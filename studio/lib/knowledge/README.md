# Conocimiento de Instagram para el agente

Guías que el agente de Studio usa al investigar, revisar artes y escribir copies:
fórmulas de ganchos (IG1–IG10), señales del algoritmo, estrategia de hashtags,
arquitectura de carruseles, checklist de copy y auditoría anti-tono-IA.

Origen: [sergebulaev/instagram-skills](https://github.com/sergebulaev/instagram-skills) (licencia MIT, ver `LICENSE.txt`).
Las mismas skills están instaladas para Claude Code en `.claude/skills/ig-*`.
